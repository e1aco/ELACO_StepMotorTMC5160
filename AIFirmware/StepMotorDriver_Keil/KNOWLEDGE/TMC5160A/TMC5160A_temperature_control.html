2. 软件层：温度感知与保护

2.1 温度感知来源

TMC5160 片上集成温度传感器，无需外部 NTC 也可保护芯片/MOSFET，共四级：

  • 预警告 OTPW（典型 120°C，上升沿范围 100–140°C）—— 芯片仍正常工作，仅置 DRV_STATUS.otpw=1，用于提示“异常工况”并触发用户降流/告警。
  • 热关断 OT（可选 136°C / 143°C / 150°C）—— 达到即两个桥的功率驱动器被关闭，置 DRV_STATUS.ot=1。
  • 自恢复逻辑：发生 ot 后，驱动器持续闭锁，直到系统温度回落到预警告电平（otpw）以下才允许重新导通，避免“反复加热到关断点”的振荡。
软件下游要点：ot 关断后芯片不会自动重新开启，必须由软件先失能（TOFF=0 或 ENN）再重新使能才能恢复。务必设计“状态上锁 + 手动/自动解锁”流程。

2.3 用 SG_RESULT 估算电机温度（软件技巧）

手册 6.5.5 说明：静止时无 StallGuard2 结果，此时 SG_RESULT 报告的是线圈 A 的斩波导通时间。由于铜线电阻随温度升高而增大，导通时间随之上升——在静止下按固定微步位置、固定电流设定测量导通时间，即可粗略单调估计电机绕组温度趋势（非绝对温度，需标定）。

2.4 软件层可用的“主动降热”手段（手册推荐）

  1. 静态降流（IHOLD + TPOWERDOWN）：静止超过 TPOWERDOWN 后自动切到保持电流 IHOLD（低于运行电流 IRUN），大幅降低待机发热。
  2. CoolStep（负载自适应电流）：中/空载时按 COOLCONF 的阈值与降比（SEIMIN/SEUP/SEDN/SEMAX）实时缩放相电流，负载降低则发热下降。适用于 SpredCycle / DcStep 等电流模式区段。
  3. StealthChop 电压 PWM：低速与静止下使用 StealthChop，静音且发热温和，配合上电电流更低的静止态。
  4. 过温主动降流预案：检测到 otpw 时，处理器主动下调 IRUN/IHOLD 或进入“限速/低功耗档”，把系统阻止在 ot 硬关断之前——这是手册“用设计避免温度关断”的直接实现。
设计提示：主动降流应做成“档位 + 去抖 + 滞环恢复”： otpw 触发 → 降流至 50~70% 或限速 → 温度回落（滞环）→ 逐档恢复；若仍升温 → ot 硬关断。不要仅凭单次 otpw 立即动作，需配合连续采样时间窗去抖。

3. 硬件层：发热、散热与热保护

3.1 热源与量化（手册 28.3 热特性）

手册给出 TQFP48-EP 封装在“双外信号层 + 两层内电平面（2s2p）JEDEC 测试板”下的参考热阻，真实值随 PCB 布局 / 板材 / 尺寸变化：

参数符号典型值说明
典型耗散PD0.6 WStealthChop 或 SpreadCycle，40/20kHz 斩波，24V，含内部稳压器
结–环境热阻RthJA21 K/W多层 2S2P 板（JEDEC 条件）
结–板热阻RthJB8 K/W距封装引脚 1mm 内 PCB 温度
结–壳热阻RthJC3 K/W结温到封装底部散热焊盘
推算思路：结温 ≈ 环境温度 + PD × RthJA。手册示例 24V · 0.6W · RthJA=21 → 结温比环境高约 12.6°C。若您的电机电源电压更高、电流更大、或 PCB 铜薄/面积小，RthJA 会明显上升，务必用 DRV_STATUS.otpw/ot 实测验证，不要照抄典型值。
手册实操标定：不接电机仅上电，电源输入消耗的功率全部视为片内耗散，用此方法可现场估算实际热阻（无负载待机功率法）。

3.3 硬件散热设计（手册第 27 章布线考虑）

  • 底部热焊盘：TQFP48-EP / QFN-WA 底部暴露焊盘必须良好焊接并直接连接大面积的 GND 平面，作为主要散热通道。
  • 地布线 / 地平面：尽量整平面地，提供低阻低热阻路径；多层板内层铜越厚，水平热扩散越好。
  • 桥臂电压与供电滤波：VM 走线尽量宽，去耦电容就近布在 VM 与 GND 之间，减小开关损耗。
  • 空气对流：手册明确空气流动可降低热阻；外壳与风道设计应对 MOSFET 与芯片有利。
  • MOSFET 选型与斜率（3.3 / 3.4 节）：合理选型与斩波斜率可减少交叉导通损耗 → 减少热源。
  • 内部稳压器热量：电源电压越高，内部线性稳压耗散越大，需纳入芯片自身热预算。

5. 当前工程缺陷排查

对照当前固件（ELA_LIB/ela_tmc5160_usr.c 等）与手册要点逐项自查：

类别排查项依据（手册）结论 / 处置建议
软件保护 （1）温度级别不区分
代码把 DRV_STATUS.bit26|bit25 合并成一个 STATUS_OTW 位。		 手册区分 otpw（预警告，可恢复、可主动降流）与 ot（硬关断、已失能）。 缺陷：两阶段合并，软件无法区分“可干预的预警告”与“已关断的硬故障”，只能被动置危险位，无法做主动降流。
（2）缺少主动降流预案 手册要求“温度上升到关断应通过设计避免”；otpw 应触发降流/限速。 风险：ela_tmc5160_get_status_flags 目前仅置标志位，未见 otpw 触发的电流/速率降级逻辑；建议增加“档位 + 滞环恢复”。
恢复逻辑 （3）ot 后的恢复流程 ot 后芯片失能，需“先失能再重新使能”，且待温度低于 otpw 才自动恢复。 风险：需确认是否有“ot 后自动解锁”与“温度低于 OTPW”的重试门控；缺失可能让驱动锁死。
（4）SPI 通讯失败的温判 温度读取依赖 SPI；SPI 异常时不可误判为正常。 已把 SPI 异常单列为 bit4，处理合理；但注意 tmc5160_is_reg_valid 的判定，防止有效值掩码掩盖真实的 otpw/ot。
硬件散热 （5）热焊盘 / 热阻裕量 RthJA=21 K/W 为 JEDEC 4 层条件，实际取决于 PCB。 需实测：若板层少、铜箔薄、无通风，结温会明显高于推算；建议用“断电、无电机、P_D=片耗散”法实测 RthJA。
（6）电源电压 / 内部稳压器 电压越高内调耗散越大（PD 含内部稳压器）。 若电源接近或超过 52V，需复核 S2G_LEVEL，避免热环境叠加误触发短路保护。
（7）MOSFET 选型 / 斩波斜率 第 3.3 / 3.4 节：斜率不匹配增加开关损耗。 检查 MOSFET 与斜率（TBL/TOFF）配置是否匹配，以及 MOSFET 自身的散热手段。
运行工况 （8）静止是否降流 IHOLD + TPOWERDOWN 引入静止降流，显著减少待机热。 确认已配置 IHOLD（低于 IRUN）与 TPOWERDOWN；否则长时间静止保持运行电流会持续发热。
（9）中空载是否开 CoolStep CoolStep 可按负载自动降流。 风险：当前固件 REG_COOLCONF=0x0000（主动关闭以保全速 StealthChop 静音）；低载/空转发热超标时可评估开启 CoolStep 或下调 IRUN。
最高优先建议：在软件中把 otpw（预警告）与 ot（关断）拆分为两个状态；otpw 触发即执行降档（下调 IRUN/IHOLD 或限速），并带“温度滞环 + 采样时间窗”去抖恢复，从而把系统阻止在硬关断之前——这正是手册“温度关断只应应急、应通过设计避免”的核心。

6. 设计落地清单（对照自查）

  1. □ 已识别并分别处理 otpw 与 ot 两个标志。
  2. □ otpw 有自动降流 / 限速预案（多档 + 去抖 + 滞环恢复）。
  3. □ ot 硬关断后，有“状态上锁 → 温度低于 otpw → 自动/手动解锁恢复”流程。
  4. □ 待机状态已用 IHOLD + TPOWERDOWN 降流，长时间静止实测不烫手。
  5. □ 低/空载工况已评估并决定是否启用 CoolStep 控流。
  6. □ 散热焊盘良好焊接、GND 面扩散充分、铜厚与面积足够；按手册方法实测热阻并确认裕量。
  7. □ 高压（≥52V）场景已复核 S2G_LEVEL，避免热环境下误触发短路保护。
  8. □ 结温估算（结温 ≈ 环境 + P × RthJA实测）在设计点下留有裕量。
  9. □ 实机满载 + 静置 + 长时间运行，结合 otpw/ot 与 SG_RESULT 记录并核对温度曲线。
