# AOD4126/AOI4126 — 100V N-Channel MOSFET

阿尔法（Alpha & Omega）SDMOS 沟槽工艺 N 沟道 MOSFET，用于 TMC5160A 外部栅极驱动桥臂（驱动器用 MOS）。

> 来源：`DATASHEET/AOD4126`（AOD4126 数据手册，Rev1，May 2012）

## 产品概要

| 参数 | 值 |
|------|-----|
| VDS | 100 V |
| ID @ VGS=10V (TC=25°C) | 43 A |
| RDS(ON) @ VGS=10V | < 24 mΩ |
| RDS(ON) @ VGS=7V | < 30 mΩ |
| 封装 | TO-252/DPAK、TO-251A/IPAK |
| 特性 | 100% UIS Tested、100% Rg Tested |

## 设计参考（TMC5160 栅极驱动相关）

- 100V/43A 额定值满足 TMC5160 外部桥臂 8~60V 供电设计。
- RDS(ON) 24mΩ 结合 TMC5160 `DRV_CONF` 斜率配置，决定开关损耗与 EMI。
- 米勒电荷 Qgd=10nC 决定栅极驱动斜率（详见硬件设计.md「选择 MOSFET 和斜率」）。
