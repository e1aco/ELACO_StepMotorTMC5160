# 步进电机 57CME13 MS31

雷赛（Leadshine）CME 系列闭环步进电机，两相混合式，内置增量式光电编码器（位置反馈）。

> 来源：`DATASHEET/57CME13 MS31.pdf` 为机械图纸（CAD 导出，仅含标题栏，无电气参数）；型号与系列特征参考雷赛 CME 系列公开资料。驱动本电机的 TMC5160 需按实测电流/编码器参数配置。

## 基本信息

| 项目 | 值 |
|------|-----|
| 型号 | 57CME13 MS31（图纸名称 `LS-57CME13 MS31`） |
| 类型 | 闭环步进电机（两相混合式） |
| 机座号 | 57（基座尺寸 57mm） |
| 步距角 | 1.8° |
| 相数 | 2 |
| 驱动方式 | 双极（4 线） |
| 编码器 | 增量式光电编码器（1000 线级） |

## 典型电气参数（CME 系列 57 机座参考）

> 以下为 CME 系列公开目录值，MS31 子型号应以厂家规格书为准。

| 参数 | 典型值 |
|------|--------|
| 额定电流 | 4 A（1.3 N·m 级别保持转矩型号） |
| 额定电压 | 建议 36 VDC 供电 |
| 保持转矩 | 1.3 N·m |

## 图纸信息（DATASHEET 原 PDF 标题栏）

- 图纸编号：`LS-MT-01-07B`，版本 `A/02`

- 环保：RoHS

## 用途在本项目中

- 由 TMC5160A 驱动（外部 MOSFET 全桥，SPI 模式 1 全功能运动控制）
- 编码器接 TMC5160 编码器接口，用于闭环位置反馈
- 具体电流/编码器线数等配置值以实际硬件调测为准（见 `ELA_LIB/require.md` 硬件配置）
