地址
n
寄存器
描述/ 位名称
4..0
BBMTIME:
导通前的关断延时：
0=最短(100ns) … 16 (200ns) … 24=最长(375ns) ，不推荐
大于24 的设置，建议BBMCLKS 替代
提示：根据开关时间的最低设置安全的，避免桥臂直
通。保留大约30 %的余量。
(复位缺省值= 0 )
11..8
BBMCLKS:
0..15: 以时钟周期为单位的BBM 时间(典型值83ns )
设定更长时间( BBMTIME 对BBMCLKS )。
(复位缺省值: OTP 4 或2)
17..16
OTSELECT:
选择桥关断的过温级别，冷却至120°C / OTPW 后恢复
00: 150°C
01: 143°C
10: 136°C (当VSA > 24V 时不推荐)
11: 120°C (不推荐，没有滞环)
提示:根据需要调整过热阈值以保护MOSFET 或PCB 上的
其他组件。(复位缺省值= % 00 )
