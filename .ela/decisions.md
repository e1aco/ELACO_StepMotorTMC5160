# 架构决策记录

## ADR-001: CAN PID调参命令码 0x06
- **日期**: 2026-07-21
- **决策**: 新增0x06命令码用于PID在线调参
- **影响**: elaco_main.c switch分支增加case 0x06

## ADR-002: EEPROM 启动自检（2026-07-31）
- **日期**: 2026-07-31
- **决策**: 新增 TEXT/ela_eeprom_test.c 弱化测试，启动时调用于 Data 块自检
- **范围**: 完整功能 + 边界（0x55/0xAA 模式、顺序数、首尾边界），仅 Data 块
- **影响**: 新增测试文件，不触碰 Calib 块（TMC 配置安全）；调用点在 elaco_main.c 可注释

## ADR-003: TMC5160 过温软件降流（2026-07-31）
- **日期**: 2026-07-31
- **决策**: 待机降流 + CoolStep 轻载节能，消除 CAN bit2 过温标志
- **背景**: 代码注释电流计算错误（203mA 实为 1.56A RMS，RS=0.05Ω），双轴持续电流致芯片 ≥143°C
- **改动**: ela_tmc5160_usr.c init() — IHOLD 4→1(0.16A)、补写 TPOWERDOWN=40(~873ms 静止降流)、COOLCONF=0xA011(CoolStep 最小 IRUN/4)、TCOOLTHRS=2000(≈10RPM 以下生效)
- **范围**: IRUN=10(1.56A) 不动，电机额定 1.5A 内；纯 SPI 配置，无硬件/驱动层改动
- **影响**: 待机热降 ~15 倍、轻载节能 ~75%；带载若丢步需回调 IHOLD 或 SEIMIN
