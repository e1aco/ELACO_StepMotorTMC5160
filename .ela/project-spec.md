# 项目规格单

## 概述
双轴步进电机驱动器，TMC5160 + STM32F407ZET6，CAN总线控制。

## CAN协议
| 项目 | 值 |
|------|-----|
| 接收 ID | 0x1AA55F42 |
| 反馈 ID | 0x1AA55F43 |

## 命令码
| 码 | 功能 | 状态 |
|----|------|------|
| 0x01 | 绝对位置移动(PID闭环) | 完成 |
| 0x02 | 相对位置正转(PID闭环) | 完成 |
| 0x03 | 相对位置反转(PID闭环) | 完成 |
| 0x04 | 速度模式(开环) | 完成 |
| 0x05 | 停止/刹车 | 完成 |
| 0x06 | PID调参 | 完成 |
