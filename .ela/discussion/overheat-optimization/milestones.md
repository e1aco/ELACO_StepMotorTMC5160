# 过温优化 — 阶段 5：里程碑

> 基于方案 B（标准）：待机降流 + 保守 CoolStep。每步可独立验证。

## S1：待机降流（IHOLD + TPOWERDOWN）

- **目标**：待机电流 0.62A → 0.16A，静止热降 ~15 倍
- **改动文件**：`ELA_LIB/ela_tmc5160_usr.c`
  - 新增 `REG_TPOWERDOWN 0x11` 常量
  - `ela_tmc5160_init()`：IHOLD 4→1，补写 `TPOWERDOWN=40`
- **验收**：电机静止 ≥1s 后测待机电流（钳表/采样电阻压降）≈0.16A；CAN 状态 bit2 在持续运转 ≥5min 后不再置位（或首次显著改善）

## S2：保守 CoolStep 节能

- **目标**：轻载运行自动降流至 IRUN/4（0.39A RMS），官方节能 75%
- **改动文件**：`ELA_LIB/ela_tmc5160_usr.c`
  - 新增 `REG_COOLCONF 0x6D`、`REG_TCOOLTHRS 0x14` 常量
  - `ela_tmc5160_init()`：`COOLCONF=0xA011`、`TCOOLTHRS=2000`
- **验收**：空载匀速运转，读 DRV_STATUS.CS_ACTUAL（bit11:13）应降至 IRUN 以下（≈1/4）；芯片温度继续下降

## S3：功能回归

- **目标**：确认降温改动未破坏既有功能
- **改动文件**：无（纯验证）
- **验收**：
  1. 定位运动（move_to/move_by）+ 编码器校验通过（无丢步）
  2. 速度模式正反转正常
  3. 闭环 PID 调参（CAN 0x06）正常
  4. EEPROM 自检通过（启动时）

## S4：温度目标达成确认

- **目标**：芯片 <143°C（bit2 消除），期望 <120°C
- **改动文件**：无（纯验证）
- **验收**：双轴连续空载运转 ≥30min，CAN 状态标志 bit2 全程不置位；可选红外测温确认表面温度

## S5：文档与留痕

- **目标**：知识沉淀
- **改动文件**：`.ela/decisions.md`（ADR-003）、`.ela/state.md`（待解决项更新）、`CONTEXT.md`（如有新术语）
- **验收**：ADR-003 记录电流公式修正 + 配置决策；state.md 移除「发热排查」待解决项

## 里程碑依赖图

```
S1（待机降流）→ S2（CoolStep）→ S3（回归）→ S4（验收）→ S5（文档）
     └──────────────┘  每步独立可验证，S1 单独就有降温效果
```

> S1 若已达成验收（bit2 消除），S2 可选做；推荐全做以获得运行段余量。
> 任何一步丢步/异常 → 回退对应寄存器写入即可（配置互不依赖）。
