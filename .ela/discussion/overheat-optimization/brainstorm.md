# 过温优化 — 阶段 4：头脑风暴

## 关键事实（全部来自数据手册 Rev1.14 + BOM 交叉验证）

| 事实 | 值 | 出处 |
|------|-----|------|
| 采样电阻 | **0.05Ω / 3W**（R10/R22/R51/R64） | BOM |
| IRUN=10 实际电流 | **(10/32)×0.25/0.05 ≈ 1.56A RMS**（峰值 2.2A） | 手册 §9 公式 |
| IHOLD=4 实际电流 | **(4/32)×0.25/0.05 ≈ 0.62A RMS**（峰值 0.88A） | 同上 |
| 代码注释「203mA/65mA」 | **计算错误，差 7.7 倍**（把 0.05Ω 当 0.5Ω） | 与 BOM 矛盾 |
| TPOWERDOWN 默认 | **10**（静止 ~218ms 后降到 IHOLD），但代码从未显式写 | 手册 0x11 寄存器 |
| StealthChop | 已启用（GCONF=0x04 正确） | 代码 |
| CoolStep | 默认关（COOLCONF=0） | 手册 |
| 过温阈值 | DRV_CONF.OTSELECT=00 → 150°C 关断；143°C 报警来自温度本身，**非阈值设置问题** | 手册 0x0A |
| 电机额定 | ≥1.5A（用户确认），**IRUN=10 顶格合理** | 用户 |
| 工作模式 | 间歇运动（动停交替），当前空载 | 用户 |

**结论**：电流配置本身没超电机额定，芯片 143°C 根源是 **TQFP48 散热能力有限 + 持续高电流**（双轴同时满载/待机 0.62A）。软件杠杆 = 待机降流 + 轻载自动降流 + （可选）全局缩放。

## 方案对比

### 方案 A：最小改动（quick win）
**内容**：只补两处——
1. `IHOLD_IRUN`：IHOLD 4→**1**（0.62A→0.16A RMS，待机热降 ~15 倍）
2. `TPOWERDOWN` 显式写 **40**（静止 ~870ms 后降流，避免动停切换频繁抖动）

| 项 | 评价 |
|----|------|
| 优点 | 改动 2 行、零风险、待机发热立竿见影；间歇运动场景收益最大 |
| 缺点 | 运行段发热不解决；电机保持力矩减到 1/4（空载无所谓，带载需评估） |
| 推荐 | ⭐⭐⭐⭐ |

### 方案 B：标准（推荐）
**内容**：方案 A + 保守启用 CoolStep——
1. `COOLCONF` = **0xA011**（SEMIN=1 开 CoolStep、SEUP=1 每值+2步、SEMAX=0、SEDN=%01 每8值降1、SEIMIN=1 → 最小电流 IRUN/4≈0.39A）
2. `TCOOLTHRS` = **2000**（TSTEP 单位 ≈ 8388 微步/s；该阈值以下速度 CoolStep 生效，阈值以上自动切 SpreadCycle）
3. 保持 StealthChop 低速静音 + 高速 SpreadCycle+CoolStep 的标准分段

| 项 | 评价 |
|----|------|
| 优点 | 运行段轻载自动降流至 IRUN/4（官方节能 75%），空载验证场景收益最大；与 StealthChop 自动分段无冲突 |
| 缺点 | 需实测确认 TCOOLTHRS 换算出速度是否合理；SpreadCycle 段噪声略大 |
| 推荐 | ⭐⭐⭐⭐⭐ |

### 方案 C：激进（全局缩放）
**内容**：方案 B + `GLOBAL_SCALER` 全局降流（如 200/256 ≈ 78%）+ PWMCONF 斩波频率优化。

| 项 | 评价 |
|----|------|
| 优点 | 全范围电流齐降，温度降幅最大 |
| 缺点 | 电机额定 1.5A 已顶格，再降**可能丢步/堵转**；需带载重测，风险高 |
| 推荐 | ⭐⭐（作为备选，仅当 B 不够时启用） |

## 推荐：方案 B（标准）

理由：
1. 用户验收目标是**消除 bit2**（芯片 <143°C），方案 B 通过「待机降到 0.16A + 轻载运行自动降至 0.39A」双管齐下，空载间歇运动场景可期把结温拉到 120°C 以下（保留余量）
2. 不动 IRUN（电机额定内不牺牲性能），仅靠 TPOWERDOWN+IHOLD+CoolStep 的"时间维度 + 负载维度"节能
3. 改动全部在 `ela_tmc5160_init()` 一处，≤5 行寄存器写入，可独立验证

## 实时性分析
- CoolStep/TPOWERDOWN 均为**芯片内部硬件机制**，SPI 一次性配置后无软件开销、无中断开销，不影响 TIM7 闭环周期（100µs 级）
- TCOOLTHRS/TPWMTHRS 分段切换由硬件 TSTEP 比较器完成，无需 MCU 干预

## 错误处理策略
1. **丢步风险**：CoolStep SEIMIN=1（IRUN/4）在空载安全；若带载实测丢步 → 升 SEIMIN=0（IRUN/2）或降 SEMIN 灵敏度
2. **切换抖动**：TSTEP 阈值自带 1/16 迟滞，避免分段临界抖动
3. **回归验证**：改动后跑既有 EEPROM 自检 + CAN 调参 + 定位/速度指令，确认功能不受影响
4. **温度观测**：通过 DRV_STATUS bit24（t120）作中间里程碑验证（<120°C 即达标），无需新增测试代码
